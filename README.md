## 📖 Deskripsi

Repositori ini berisi kumpulan tugas dan praktikum pemrograman web yang mencakup pembelajaran HTML dan CSS. Proyek ini terdiri dari dua modul utama yang masing-masing fokus pada aspek berbeda dari pengembangan web.

## 🗂️ Struktur Proyek

```
portofolio-pemweb/
├── Modul1/
│   ├── Tugas1.html          # Formulir pendaftaran mahasiswa
│   └── logo stitek.png      # Logo institusi
└── Modul2/
    ├── Tugas Modul 2.html   # Praktikum CSS dengan layout responsif
    └── Mystyle.css          # File stylesheet eksternal
```

## 📚 Detail Modul

### Modul 1: HTML Fundamentals

**File:** `Modul1/Tugas1.html`

- **Tujuan:** Mempelajari elemen-elemen dasar HTML
- **Fitur:**

  - Formulir pendaftaran mahasiswa baru yang lengkap
  - Penggunaan berbagai input types (text, email, radio, checkbox, select, textarea)
  - Implementasi fieldset untuk pengelompokan form
  - Validasi form dengan atribut `required`
  - Integrasi logo institusi
  - Link eksternal ke website kampus

- **Elemen yang Dipelajari:**
  - Form elements dan validasi
  - Input types dan attributes
  - Semantic HTML structure
  - Image integration
  - External links

### Modul 2: CSS Styling & Responsive Design

**File:** `Modul2/Tugas Modul 2.html` dan `Modul2/Mystyle.css`

- **Tujuan:** Mempelajari styling CSS dan desain responsif
- **Fitur:**

  - Layout grid system dengan CSS Grid
  - Desain responsif untuk berbagai ukuran layar
  - Styling komprehensif dengan CSS internal dan eksternal
  - Media queries untuk mobile-first approach
  - Color scheme dan typography yang konsisten

- **Teknik yang Dipelajari:**
  - CSS Grid Layout
  - Responsive Web Design
  - Media Queries
  - Flexbox untuk centering
  - CSS Box Model
  - External stylesheet integration

## 🚀 Cara Menjalankan

### Prasyarat

- Web browser modern (Chrome, Firefox, Safari, Edge)
- Text editor (opsional, untuk melihat kode)

### Langkah-langkah

1. Clone atau download repositori ini
2. Buka file HTML yang diinginkan di web browser:
   - Untuk Modul 1: Buka `Modul1/Tugas1.html`
   - Untuk Modul 2: Buka `Modul2/Tugas Modul 2.html`

## 📱 Fitur Responsif

Proyek ini mengimplementasikan desain responsif dengan breakpoints:

- **Desktop:** > 768px (3 kolom grid)
- **Tablet:** ≤ 768px (2 kolom grid)
- **Mobile:** ≤ 480px (1 kolom grid)
